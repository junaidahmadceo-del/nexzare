Gemnix – Bulk Image Generator for Gemini

A Chrome extension that turns a text file of prompts into a folder of finished images on Gemini — with the same character in every picture.

What it does

Hundreds of images. One click.

Bulk prompts

Load a .txt file with one prompt per line. Gemnix sends them to Gemini one by one and waits for each image.

Reference character

Add your character sheet once (up to 3 images). It is attached to every prompt, so the same character appears in every image.

Auto-download

Every image is saved to your Downloads folder with a numbered name in prompt order (e.g. 001_Your_Prompt_Words.png), in one folder per prompt file.

More features

  • The side panel sits next to Gemini and can be resized.
  • Pause, resume, stop, and “start from prompt #”.
  • Automatic retries and one-click retry for failed prompts.
  • “Run in background” keeps generating while you use other tabs.
  • Progress is saved.
How it works

Four steps to a folder of images.

  1. STEP 01

    Install Gemnix from the Chrome Web Store and open gemini.google.com.

  2. STEP 02

    Click the Gemnix icon; the side panel opens next to Gemini.

  3. STEP 03

    Choose your prompt file, add a reference image if you want one, and press Start.

  4. STEP 04

    Your images download automatically. Turn on “Run in background” to keep working in other tabs.
